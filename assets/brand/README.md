# Brand assets (source art)

Drop original art here — Oliver populates this folder. Suggested for now (we'll formalize categories/dimensions later in `docs/assets.md`):

- `avatar/` — the OddSense avatar at native pixel size (PNG) plus any upscales; transparent-background version if available
- `skin/` — the actual Minecraft skin PNG(s)
- `banners/` — YouTube/Modrinth banners
- `project-icons/` — icons from Modrinth projects
- `art/` — other original art, thumbnails, textures worth showing

Prefer PNG for pixel art (no smoothing), SVG for vector, keep originals unmodified.
